# Firefox extension — discontinued

There is no Firefox version of Full Browser Sync, and none is planned.

## Why

A Firefox port of this extension existed and was submitted to Mozilla's AMO
review process. It was rejected so quickly that no meaningful human review
could have taken place, and Mozilla provides no practical way to contact a
real person to question or appeal the outcome.

The maintainer's policy is to not deal with organisations that deliberately
make themselves hard to contact — so rather than fight the process, Firefox
support was dropped. The Chromium extension in `extension/` remains fully
supported.

## Want to pick it up?

If you've had a better experience with Mozilla and would like to maintain a
Firefox version, you're welcome to. The last Firefox source remains in the
git history — check the commit that emptied this directory, or the commit
immediately before it. Open an issue on the repository to discuss.
